About the crawler

If you found this page in your server logs, here's what came knocking.

User agentKawaiiShopHopBot/1.0
What it doesRequests the home page of each shop in the ring, once a day, and checks the HTML for that shop's ring links.
What it storesThe date, the HTTP status, and whether the links were found. Nothing else. No page content is kept.
RateOne request per shop per day, a few seconds apart.
Opting outAsk to leave the ring and it stops the same day.

The whole ring — member list, build script, crawler — is open at github.com/toothachebrand/kawaii-shop-hop.
