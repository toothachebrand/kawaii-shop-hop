Add your shop

The ring is small on purpose and every shop is read by a person before it goes in. Here's the whole process.

1. Send your details

Fill in the short form on the Toothache site: shop name, address, one line about what you make, and an email we can reach you at.

Open the form

2. We reply with your slug

Your slug is your shop's short name in the ring — toothache, for instance. It goes in the code below and never changes.

3. Paste the code on your site

Anywhere a visitor will see it: footer, sidebar, an "internet friends" page. Swap YOUR-SLUG for the slug we send you.

<!-- Kawaii Shop Hop -->
<div class="kawaii-shop-hop" style="text-align:center;font:12px sans-serif;padding:14px 0">
  <a href="https://ring.toothacheshop.com/prev/YOUR-SLUG/">&#8592; prev</a>
  <a href="https://ring.toothacheshop.com/" style="margin:0 10px"><img
     src="https://ring.toothacheshop.com/badge/badge.svg"
     alt="Kawaii Shop Hop" width="88" height="31" style="vertical-align:middle"></a>
  <a href="https://ring.toothacheshop.com/next/YOUR-SLUG/">next &#8594;</a>
</div>

It's plain HTML on purpose. No script tag, so it survives Shopify rich text, Squarespace code blocks, Wix embeds, WordPress custom HTML, Neocities and Carrd alike. Restyle it however you like — the crawler only looks for the two links, not the styling.

4. Tell us it's live

Reply to the email and we'll add you. Once you're in, your prev and next links start working immediately.

Staying in

  • A crawler visits each shop once a day and checks the code is still on your page.
  • If your site is simply unreachable — maintenance, a firewall, a bad afternoon — that's not held against you.
  • If the code is gone for three days running we email you.
  • After fourteen days we quietly take the shop out of the rotation. Your record stays, so coming back is one email.

No website?

If you sell through Instagram or TikTok alone, you can still be listed as a friend of the ring on the front page. You can't be part of the hop itself, because a profile page can't carry a visitor on to the next shop.
